== Purpose

This page will describe the recurring activities required to operate a Hamoni
deployment. It is not yet written.

== Known activities

* Database schema upgrades are applied automatically and transparently through
  Flyway as part of a Hamoni upgrade.
* Blob storage retention must clean up documents once no process references them.
* Database backups and restore procedures must be defined for each platform.
* Blob storage backups and restore procedures must be defined.
* Monitoring, logging and alerting must be defined.
* A rolling upgrade must remain compatible with the previous application version
  while the rollout completes.
