== Purpose

The Docker Compose platform is for local integration testing and proof of
running. It is not an enterprise deployment and does not provide the scaling or
availability of a supported platform.

== Local stack

The local platform uses:

* MariaDB for the relational database.
* A local filesystem volume for blob storage.
* NGINX for ingress.
* An organisation-provided OIDC service; no local Keycloak is included.
* A static key provider for the credential manager.
* RabbitMQ for messaging.
* The local Docker image store; no image registry is required.
* An installer-provided email server; no email service is included.
* No object cache: the in-memory cache is used, which limits the deployment to a
  single Control Room instance.
* Local provisioning instead of SCIM.
