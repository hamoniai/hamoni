== Current position

AWS EKS is the only available Kubernetes platform. Deployment detail for EKS is
not yet written.

== Reference bundle

The AWS EKS platform bundle uses:

* EKS for the Kubernetes cluster.
* Application Load Balancer for ingress.
* ECR for images.
* RDS for the relational database.
* ElastiCache for Redis for the object cache.
* S3 for blob storage.
* SQS for messaging between the Control Room and the Process Runner.
* KMS for the credential-manager key source.
* An organisation-provided OIDC provider, with optional SCIM.
* An organisation-provided email server.
