== Current position

Hamoni can run on basic virtual machines, such as EC2 instances. The same
capabilities are required as for the Kubernetes platform. The difference is that
the deployer manages the instances, scaling, failover and upgrades.

Managing EC2 or equivalent virtual machines is outside the scope of Hamoni. A
supported AWS EC2 platform bundle is planned but not yet defined.

== Reference bundle

The planned AWS EC2 platform bundle is expected to use the same services as the
AWS EKS bundle, with EC2 replacing EKS as the compute platform.
